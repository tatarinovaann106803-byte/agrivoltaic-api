> API сервис для расчета эффективности агривольтаических систем — совместного размещения солнечных панелей и сельскохозяйственного производства (растениеводство, аквакультура, лесное хозяйство).

## 📋 О проекте

Сервис позволяет рассчитать экономическую и энергетическую эффективность агривольтаической системы на основе:
- **Методики PVsyst** для расчета выработки электроэнергии
- **AI моделей (Random Forest)** для предсказания изменения продуктивности сельского хозяйства
- **Реальных данных** из CSV файлов с экспериментальных АВ-проектов

### Что рассчитывает сервис:
- ⚡ **Энергетика:** количество панелей, мощность, годовая выработка, удельная выработка, угол наклона
- 🌾 **Сельское хозяйство:** предсказание изменения урожайности/продуктивности
- 💰 **Экономика:** CAPEX, OPEX, чистая прибыль, срок окупаемости (ROI), доход от энергии и продукции

### Поддерживаемые сектора:
| Сектор | Иконка | Что предсказываем | Единица измерения |
|--------|--------|-------------------|-------------------|
| Растениеводство | 🌾 | Изменение урожайности | % |
| Аквакультура | 🐟 | Продуктивность | т/га |
| Лесное хозяйство | 🌲 | Прирост древесины | м³/га/год |

## 🚀 Быстрый старт

### Предварительные требования
- Python 3.9+
- Git

### Установка локально

```bash
# Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/agrivoltaic-api.git
cd agrivoltaic-api

# Создайте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows

# Установите зависимости
pip install -r requirements.txt

# Обучите модели
python train_models.py

# Запустите сервер
python app.py
# или
uvicorn app:app --reload --port 8000
